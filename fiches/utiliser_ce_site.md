# Utiliser ce site

Pour trouver cette fiche, vous avez utilisé le **menu**.

Le **menu** permet de :
* Retourner sur l'**accueil**
* **Créer** une fiche à partir d'un formulaire
* **Importer** une fiche (au format *.md*) depuis l'appareil
* Importer **un lot** de fiches (au format *.bristol*) depuis l'appareil
* **Supprimer** une ou plusieurs fiches.

On peut également :
* **Masquer / afficher** une matière et une catégorie en cliquant sur son nom
* **Changer la couleur** d'une matière
* **Réinitialiser** la couleur d'une matière
* **Déplacer** des fiches entre elles, entre catégories, et entre matières
* **Accéder** à une fiche

**=> Il existe 2 types de fiches :**
* Les fiches **imposées** → il s'agit de fiches ne pouvant pas être déplacées, modifiées ou supprimées
* Les fiches **locales** → il s'agit de **vos** fiches, vous pouvez les déplacer, les modifier, les déplacer...

Depuis le menu de visualisation d'un fiche, on peut :
* Retourner sur l'**accueil**
* **Exporter** la fiche vers un fichier *.md*
* **Modifier** la fiche via un formulaire (seulement pour les fiches locales)
* **Supprimer** la fiche (seuelement pour les fiches locales)
